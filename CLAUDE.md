# Instructions for Claude sessions

This is Kosuke's personal Blue Zone workspace. Read `README.md` for layout and conventions.

- Follow the privacy rules in `README.md`. Never commit secrets, personal data about guests,
  tenants, students or staff, or confidential business documents. If a task needs such data,
  keep it outside the repo and say so.
- New work goes in `projects/YYYY-MM-short-name/`, copied from `templates/project/`.
- Handoffs go in `handoffs/YYYY-MM-DD-topic.md`, based on `templates/handoff.md`. Include a
  suggested model and effort level for the next session.
- Japanese deliverables are written natively in Japanese; English uses American spelling.
- Mark claims as measured, recorded or inferred; never fill in missing data silently.
- Record default choices made while the user was away in the project README.
- Work on a `claude/*` branch and open a draft pull request; do not push to `main` directly.
